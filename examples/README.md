# Examples

Runnable demos and one-off scripts. **Not** imported by `src/lib.ts`; safe to ignore for embedders.

| File | Notes |
|------|--------|
| `lit_point_light_main.ts` | Desktop loop: `RaylibRenderer` + lit scene |
| `extract_scene.ts` | CLI-style extraction dump |
| `extract_webgpu_node_material_colors.ts` | WebGPU / node materials smoke test |
| `r3f_cubes_room.tsx`, `r3f_lit_scene.tsx` | R3F + Raylib window |
| `xr_cubes_room.ts` | XR-oriented sample |
